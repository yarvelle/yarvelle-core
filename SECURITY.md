# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Yarvelle Core seriously. If you believe you have found a security vulnerability, please do NOT open a public GitHub issue.

Instead, please report security issues to:
**security@spectrayan.com**

Please include:
1. Type of vulnerability and affected component (`backend/` or `frontend/`).
2. Step-by-step reproduction instructions or proof-of-concept.
3. Potential impact and severity assessment.

We will acknowledge receipt within 48 hours and provide a timeline for remediation.
