# Rubric: synthesis

Score how well the final answer combines agent findings into a clear reply
for the user. The answer must not leak internal agent ids or tool names.

| Score | Meaning |
| --- | --- |
| 5 | Clear, complete synthesis; cites useful facts; no slug or tool leaks. |
| 4 | Mostly complete; minor omission; no leaks. |
| 3 | Partial synthesis; missing an important fact or slightly confusing. |
| 2 | Weak or wrong synthesis; or leaks an agent id / internal name. |
| 1 | No usable synthesis, or invents facts, or heavy internal leakage. |
