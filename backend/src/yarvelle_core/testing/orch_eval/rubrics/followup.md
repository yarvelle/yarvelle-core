# Rubric: follow-up

Score whether a follow-up turn stays on the same task and agent intent
without unnecessary re-routing or dropping the thread.

| Score | Meaning |
| --- | --- |
| 5 | Follow-up is handled coherently on the same thread. |
| 4 | Mostly coherent; small redundancy. |
| 3 | Partial; re-asks or soft-resets context. |
| 2 | Drops the thread or restarts from scratch without need. |
| 1 | Contradicts the prior turn or changes topic incorrectly. |
