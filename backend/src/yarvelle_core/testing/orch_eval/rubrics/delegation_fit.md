# Rubric: delegation fit

Score whether the agents that ran (and the final answer) fit the user's
request — right specialist(s), no forbidden or hidden agents.

| Score | Meaning |
| --- | --- |
| 5 | Right agent(s); answer matches what they should produce. |
| 4 | Reasonable agent choice; minor mismatch in emphasis. |
| 3 | Borderline agent choice or incomplete use of the specialist. |
| 2 | Wrong specialist, or a hidden/forbidden agent influence. |
| 1 | Clearly wrong routing reflected in the answer. |
