# Rubric: context carryover

Score whether the answer correctly uses facts established in earlier turns
of the same conversation (names, amounts, dates, decisions).

| Score | Meaning |
| --- | --- |
| 5 | All prior facts needed for this turn are used correctly. |
| 4 | Uses prior context with at most a minor slip. |
| 3 | Uses some context but misses or softens an important prior fact. |
| 2 | Ignores or contradicts a clear prior fact. |
| 1 | Treats the turn as isolated or invents conflicting history. |
